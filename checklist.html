⚙️ 체크박스 항목 관리

💡 각 보조메뉴(카테고리) + 라인 + 대상 + 점검/급지 포인트 조합별로 회차 입력 시 나타나는 체크박스 항목을 관리합니다.
📌 입력하는 즉시 자동 저장되며, 각 보조메뉴 페이지에서 조건이 일치하는 행에 체크박스가 자동 표시됩니다.
예) 예비소성로 / 1라인 / 충진기 / 베어링 → 체크박스: 상부, 하부
카테고리(보조메뉴) 라인 대상 점검/급지 포인트 체크박스 항목 (콤마로 구분) 상태 / 작업
