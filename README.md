# 설비관리 테스트 V1 (기계1파트)

포스코퓨처엠 기계1파트 설비 이력관리 시스템입니다.

## 기능
- 로그인 (아이디: 1004 / 비밀번호: 1005)
- 대시보드 (차회수리일자 도달 현황, 진행률 그래프)
- 급유급지관리 (예비소성로, 본소성, 열처리, 혼합설비, 필터프레스, 진공건조기, 냉각기)
- 관리 (통합 조회)
- 필터 및 자동완성 드롭다운

## 사용 방법
1. GitHub Pages 활성화 후 `index.html` 접속
2. 로그인 후 대시보드 이용

## 기술 스택
- HTML5 / CSS3 / JavaScript (Vanilla)
- Chart.js (그래프)
- LocalStorage (데이터 저장)
